# Business Performance Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze retail sales performance across regions, product categories, and months. The dashboard presents key business metrics to support data-driven decision-making.

## Objectives
- Track total revenue, total profit, order count, and profit margin.
- Compare revenue across regions and product categories.
- Analyze monthly revenue trends.
- Explore sales performance using interactive filters.

## Tools Used
- Microsoft Power BI
- SQL
- CSV dataset
- GitHub

## Dashboard Features
- **KPI Cards:** Total Revenue, Total Profit, Total Orders, and Profit Margin.
- **Revenue by Region:** Compares sales across regions.
- **Revenue by Product Category:** Identifies category-level performance.
- **Monthly Revenue Trend:** Tracks revenue over time.
- **Interactive Filters:** Region, Category, and Date.

## Dataset
The project uses a small illustrative retail sales dataset containing order dates, regions, product categories, quantities, revenue, cost, profit, and payment methods. The sample data is for demonstration and does not represent actual business transactions.

## Key Analysis
The dashboard can be used to identify higher-revenue regions, compare category performance, track monthly changes, and evaluate profitability.
